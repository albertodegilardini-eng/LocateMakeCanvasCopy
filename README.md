
  # Locate Make Canvas (Copy)

  This is a code bundle for Locate Make Canvas (Copy). The original project is available at https://www.figma.com/design/WoKILfvhY7h3Yw8uXX7jGE/Locate-Make-Canvas--Copy-.

**Data note (2026)**: Listings use realistic base attributes (prices, sizes, recs) sourced from current Inmuebles24 + Lamudi/Vivanuncios rental results for Santa Fe (Península, Torre 300, Paradox). Scores/DOM/anchors are demo overlays.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
